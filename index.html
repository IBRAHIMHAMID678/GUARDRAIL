🛡️ About Guardrail Lab

Adversarial AI coding agent permission firewall & 3D defense interceptor

Guardrail Lab is a deterministic, client-side adversarial test harness and interactive 3D WebGL simulator. It exposes the critical flaw in AI coding agent guardrails: confusing naive string/regex blocklists with POSIX shell execution semantics.

The problem it solves

When engineers deploy autonomous AI coding agents (Claude Code, Cursor, Copilot, Aider), they guard shell permissions with simple blocklists like git commit or rm -rf — and assume the guardrail blocks the operation. In reality it blocks only one specific byte sequence. POSIX shell can express the identical operation dozens of ways: 

git -C /repo commit -m "fix"      # interleaved flags
echo ok && git commit             # chained pipeline
/usr/bin/git commit               # absolute path
env git commit                    # env wrapper
$(which git) commit               # subshell substitution
"git" commit                      # quote evasion

A standard regex or substring matcher fails against over 70% of realistic evasion vectors. Guardrail Lab lets you simulate, visualize, and harden these defenses before an agent breaches your system.

How it works
  1. Select a threat policy — 6 OWASP-mapped agent threat domains, 49 curated adversarial vectors.
  2. Fire evasion vectors — type any shell command or hit a quick-attack chip (flag insertion, chained &&, subshell, env wrapper, quote evasion).
  3. Compare enforcement — Naive Substring (porous, bypassed) vs Hardened AST (POSIX syntax-tree tokenization, impervious).
  4. Watch the 3D interceptor — blocked commands shatter against the quantum shield in an emerald burst; bypasses crash into the server core in a crimson breach wave.
  5. Export the hardened rule — one-click deployment configs for Claude Code, Cursor, AgentSH, POSIX bash hooks, and Docker/Seccomp.
